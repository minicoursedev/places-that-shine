洋流地圖 APP

隱私權政策

適用服務：洋流地圖 App 與本支援網站。更新日期：2026 年 10 月 21 日。App 維護及隱私聯絡人：梁力基。

1. App 使用與資料

洋流地圖提供台南店家瀏覽、地圖與限時幸運星訊息，無須註冊帳號。App 未設置廣告、使用者行為分析或開發者自有的個人資料伺服器，不要求存取通訊錄、照片或麥克風。我們不出售使用者個人資料。

2. 位置權限

點擊「我的位置」或「幸運星」時，App 才會請求使用期間的位置權限，用於顯示目前位置，或在裝置上挑選最近的有效活動。App 不在背景追蹤位置，也不建立定位歷史或將座標上傳到開發者的伺服器。地圖顯示仍需連線至 Google Maps。

你可以拒絕定位，或在 iOS「設定」中變更洋流地圖的位置權限。拒絕後仍可瀏覽店家與地圖；幸運星會改為隨機選取有效活動。

3. 裝置內保存

App 在手機保存公開店家資料與最後成功更新時間，以加快載入並在連線失敗時提供已下載的資料。位置僅供當次使用，不寫入店家快取。刪除 App 可移除其裝置內資料；系統備份依你的 iOS／iCloud 設定管理。

4. 第三方連線與服務

App 使用 Google Maps SDK 顯示地圖，並從 GitHub 下載公開店家與活動資料。載入店家圖片時，也可能連線至圖片提供者。這些服務可能處理 IP 位址、裝置資訊、使用與診斷資料等連線所需資訊，保存方式依各服務政策而定。

請參閱 Google 隱私權政策、Google Maps SDK 隱私說明與 GitHub 隱私權聲明。點擊導航或社群連結後，會開啟外部服務，並適用該服務的隱私權政策。

5. 支援網站與來信

本網站使用 GitHub Pages 提供網頁，並使用 Google Analytics 統計瀏覽情況；可能使用 Cookie 與處理裝置、瀏覽及連線資訊。這是網站的統計服務，App 本身未整合 Google Analytics。你可透過瀏覽器管理 Cookie，或使用 Google Analytics 停用工具。

若你以電子郵件聯絡我們，我們會使用你提供的電子郵件、問題內容與附件回覆及處理支援需求，僅在處理及必要後續聯繫期間保留。請避免提供密碼、身分證件或其他無關的敏感資料。

6. 查詢、刪除與政策更新

若要查詢、更正或刪除你在支援來信中提供的資料，或對本政策有疑問，請聯絡 lman.services@brain-c.com。第三方持有的資料請依其政策提出申請。功能或資料處理方式變更時，我們會更新本頁與更新日期。
